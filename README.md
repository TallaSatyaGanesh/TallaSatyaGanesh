## 🚀 Featured Projects

### 🤖 Agentic AI RFP Analysis & Proposal Response System

A multi-agent AI application designed to streamline the analysis of
Request for Proposal (RFP) documents and support proposal preparation.

**Key features**
- RFP requirement extraction and classification
- Compliance analysis and risk identification
- AI-assisted proposal generation and review
- Human-in-the-loop approval workflow
- DOCX proposal export

**Tech stack:** Python, FastAPI, LangGraph, LangChain, RAG,
ChromaDB, React, TypeScript, SQLAlchemy

### ♿ Vision-Based Assistive Perception System

An AI-powered assistive mobile application designed to help visually
impaired users understand their surroundings through voice assistance.

**Key features**
- Image and short-video input
- AI-powered scene understanding and descriptions
- English and Telugu voice-assisted interaction
- FastAPI backend with REST APIs
- Input validation and error handling

**Tech stack:** Flutter, Dart, Python, FastAPI, Gemini Vision,
Google GenAI SDK, REST APIs

### 🧬 Machine Learning for Bioinformatics

A research project focused on machine learning, gene expression
analysis, and hub gene identification for cervical cancer biomarker
research.

**Key features**
- Gene expression data analysis
- Feature selection and dimensionality reduction workflows
- Protein-protein interaction network analysis
- Hub gene identification
- Model explainability using SHAP and LIME

**Tech stack:** Python, Pandas, NumPy, Scikit-learn, STRING database

### 🛒 Online Grocery Management System

A full-stack grocery management and e-commerce application supporting
product management and shopping workflows.

**Key features**
- CRUD operations for grocery management
- Product categories and filtering
- Shopping cart functionality
- Database-backed application workflows

**Tech stack:** Java, JSP, Servlets, JDBC, MySQL, HTML, CSS, JavaScript
